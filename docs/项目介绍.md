# 学习 OS · 项目介绍

> 一个 Android 优先、本地优先的个人学习管理应用。
> 用 React + TypeScript + Capacitor 写成；数据只保存在你自己的设备上，没有账号、没有后端、没有排行榜。

---

## 为什么做它

市面上的学习 App 大多在两个方向上用力：要么做社交与排行榜，把学习变成比较；
要么做云端同步与会员，把数据放到别人的服务器上。

这个项目反着来：

- **只记录，不评判**：今天学了多少、连续了几天、离目标还差多少，如实显示；不催、不排名、不制造焦虑。
- **只在本机**：没有账号系统，没有云同步，导出/导入就是本地 JSON 文件。
- **按真实时间算**：计时用真实时间戳，暂停不计费，切后台/锁屏如实计时；学习时长只来自计时器或手动补录。
- **对眼睛和键盘友好**：六套主题、玻璃材质、深色/省电模式；小字对比度有机器门禁，键盘能走完整流程。

它最初是给一个高中生日常用的：早上看今天要做什么，放学后计时，晚上看统计与连续天数。
功能都是按真实使用场景长出来的，不是按「功能清单」堆的。

## 适合谁

- 想要一个**安静、不社交、数据在自己手里**的学习记录工具的人。
- 喜欢自己折腾：能接受侧载 APK、愿意看文档甚至改代码的人。
- Android 用户（主力目标平台）；Web 版也能跑，但通知等系统能力受限。

## 不适合谁

- 需要多设备同步、班级/小组协作、家长端的人。
- 想要排行榜、打卡社交、学习社区的人——这些是明确不做的。
- iOS 用户：代码结构上可以移植 Capacitor iOS，但本项目没有做 iOS 工程与验证。

## 核心功能

| 模块 | 能做什么 |
|---|---|
| 首页 | 今天自学多久、还能学多久、离睡觉多久；「现在该做什么」推荐；今日课程、重要日期、固定日程 |
| 目标与作业 | 计时目标/成果目标；计划时长可留空（不限时长）；作业清单按科目分组 |
| 计时 | 真实时间戳、暂停不计、后台/锁屏如实计时；专注模式；结束后自评分与评价 |
| 统计 | 概览、日历、热力图、考试成绩 vs 目标分、成就 10 项；学习评价（规则引擎，不编造） |
| 火花 | 连续学习天数；断签两日修复规则；接回有复燃动画；缺口日不算学习时间 |
| 设置 | 六套主题、玻璃参数、作息按星期几、课程表、背景图、重要日期、数据导入导出 |

## 设计原则（也是代码硬约束）

1. **不写死颜色**：所有颜色走语义令牌，换主题不漂移。
2. **不造假数据、不做假按钮**：没数据就给引导，数字必须来自真实记录。
3. **学习时长只来自计时或补录**：录成绩、完成任务、接回火花都不产生时长。
4. **不做排行榜与竞争**：成就只跟自己的记录比。
5. **本地优先**：联网能力必须可选，未配置时静默关闭。
6. **文案克制**：不用感叹号、不吹、不说教。

## 技术栈

React 19 · TypeScript（strict）· Vite 7 · Tailwind 4（CSS-first tokens）· Zustand
· React Router（HashRouter）· Capacitor 8（Android）· PWA
· 自研玻璃材质（WebGL 折射 / 独立模糊层）· Playwright 驱动的视觉与像素审计

## 质量与验证

这个项目比较少见地把「测试与审计」当成产品的一部分：

- **完整回归 55 个用例**：功能 + 竞态 + 像素审计 + 无障碍，全部通过（约 21 分钟）。
- **对比度门禁**：真实像素审计（78 组合要求 0 条低对比）+ 令牌级确定性审计（216 组合，最低 5.05:1）。
- **布局审计**：10 种视口 × 13 条路由，溢出/触控目标/遮挡/字号全部检查。
- 这些不是口号：颜色或布局退步，回归会直接失败。

## 数据与隐私

- 学习数据保存在本机 IndexedDB / localStorage（Android WebView 内同源）。
- 没有账号；导出/导入是本地 JSON。
- 仅有的网络请求都是可选的：网络校时（失败回退本机时间）、更新检查、意见箱；后两者未配置端点时不出现。
- 没有埋点、没有分析 SDK、没有第三方登录。

## 已知边界与未完成

- **系统通知/提醒未做**：需要 Android 权限与双机真机验证，规划在 1.5.0。
- **没有多设备同步**：这是产品选择，不是遗漏。
- 真机验证目前只有开发者的华为设备；三星等机型仍需补验。
- 代码是个人项目，目录与命名有历史痕迹；欢迎 PR 改进。

## 下载与安装

见 GitHub Releases：

| 文件 | 用途 |
|---|---|
| `LearningOS-vX.Y.Z.apk` | 直接装到 Android 手机（覆盖升级会保留数据） |
