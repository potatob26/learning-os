# v1.4.2 · 第一天也能看到火花入口

只是一个小修：

- 以前「还没有任何学习记录」时，首页右上角的火花徽章是隐藏的——新用户第一天根本找不到火花页。
- 现在徽章一直在：空状态显示「开始」，断签后显示「重新开始」，有连续天数时显示「N 天」，都点进同一个火花页。
- 火花页在空状态给出「还没有第一天：今天学满 10 分钟，就有了第一天」的引导。

验证：`test-streak-rescue` 37→**39/39**（新增第一天徽章与空状态引导断言）、`e2e` 28/28、`tsc` 0 错。
