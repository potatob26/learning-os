# v1.4.3 · 进入软件自动检查更新

这一版只做了一件事：把「检查更新」真正接起来，开源后不用再自己维护版本服务器。

## 新增

- **进入软件自动检查更新**：启动后安静地查一次 GitHub Releases（6 小时最多一次）。
  - 有新版本：弹「发现新版本」，显示版本号与更新说明，点「下载并安装」打开浏览器下载 APK；
  - 同一版本点过「以后再说」不再提醒，出现更新版本会再提；
  - 离线 / 超时 / 服务器错误 / 版本号格式不对，一律静默当作「没有更新」，不打扰；
  - 不发送任何学习数据，也不需要你配 GitHub token（匿名查询）。
- **平台限制（如实说明）**：安卓侧载应用不允许静默自更新，所以只能「提示 + 引导下载」，
  下载后仍需系统安装器确认；这一点不是没做，是平台边界。

## 启用条件

本版构建时已写入默认仓库 `potatob26/learning-os`。发布新版本时：

1. GitHub 上打 tag `v1.4.4`（版本号要比当前大）；
2. Release 里上传 `LearningOS-v1.4.4.apk`；
3. 已安装的 1.4.3 启动后就会自动发现并提示。
