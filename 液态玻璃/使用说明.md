# 液态玻璃组件

直接双击 `index.html`，可以查看完整演示。也可以通过本地 Web 服务器打开。

## 文件说明

- `liquid-glass.js`：核心液态玻璃组件。接入其他项目时必须复制。
- `shapes.js`：演示页中的形状选择和自定义顶点编辑器。
- `app.js`：演示页交互、背景和参数控制。
- `style.css`：演示页界面样式。
- `index.html`：完整演示网页。

## 最小接入方式

```html
<script defer src="./liquid-glass.js"></script>

<div style="position: relative; height: 500px; background: #17313b">
  <liquid-glass
    width="280"
    height="200"
    shape="rounded"
    radius="48"
    refraction="55"
    blur="1"
    chromatic
  >
    你的内容
  </liquid-glass>
</div>
```

支持的 `shape` 值：`rounded`、`ellipse`、`capsule`、`diamond`、`hexagon`、`star`、`custom`。

自定义轮廓示例：

```html
<liquid-glass
  width="280"
  height="220"
  shape="custom"
  points="15,10 85,10 95,60 60,95 10,80"
>
  你的内容
</liquid-glass>
```

`points` 使用 0–100 的相对坐标，按轮廓顺序填写 3–16 个顶点。
