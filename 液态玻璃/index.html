把玻璃带到你的项目

下载组件后，使用原生 Web Component，无需安装依赖，也可以直接双击打开本演示页。

<script defer src="./liquid-glass.js"></script>
<div style="position:relative;height:500px">
  <liquid-glass width="280" height="200"
    shape="rounded" radius="48" draggable>
    你的内容
  </liquid-glass>
</div>

默认使用背景模糊与玻璃高光，可放在普通网页内容上。需要本页的精准折射时，将背景 Canvas 传入组件：

glass.source = backgroundCanvas;
glass.setPosition(100, 100);
// 背景更新后重新渲染
glass.render();

shape 支持 rounded、ellipse、capsule、diamond、hexagon、star 和 custom。自定义轮廓使用 0–100 的坐标，按轮廓顺序填写 3–16 个顶点：

<liquid-glass width="280" height="220" shape="custom"
  points="15,10 85,10 95,60 60,95 10,80">
</liquid-glass>

Canvas 需与父容器对齐并覆盖父容器，使用可读取的本地或跨域授权图片。网页实现模拟液态玻璃，并非 Apple 原生材质；WebGL 不可用时自动回退。
