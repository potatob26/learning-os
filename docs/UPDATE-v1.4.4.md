# v1.4.4 · 设置里可以手动检查更新

## 新增

- **设置 → 数据 → 「检查更新」按钮**：点一下立即检查，不受 6 小时自动检查的节流限制。
  - 有新版本：弹出「发现新版本」，显示版本号与更新说明，可下载 APK；
  - 已是最新：显示「已是最新版本 v1.4.4」；
  - 网络不通 / 超时 / 服务错误：显示「检查失败，稍后再试」，不重复弹窗；
  - 未配置更新源的构建：显示「当前构建没有配置更新源」。
- 自动检查保持原样：启动后 6 小时最多一次，失败静默。

## 平台限制（如实说明）

安卓侧载应用不允许静默自更新，手动/自动检查都只能「提示 + 引导下载」，
下载后仍需系统安装器确认。

## 验证

- `test-github-update` **24/24**：自动检测、版本比较、APK 链接、节流、无仓库不发请求、
  500/坏 tag 静默、force 绕过节流、APK 缺失提示、设置页手动检查（有新版/已是最新）。
