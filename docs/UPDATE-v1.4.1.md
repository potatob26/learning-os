# v1.4.1 · 火花有了自己的页面，小字更清楚，键盘也能用了

这一版没有加新模块，三件事：把火花从弹层升级成独立页面、把看不清的小字修到位、把键盘和读屏走不通的路补上。

## 火花

- **独立页面**：首页右上角的「火焰 + N 天」点进去就是火花页（`#/streak`）。当前连续、历史最长、近 30 天格子、断签挽救进度、接回记录都在这里，不再挤在底部弹层里。
- **首页更明确**：徽章从一个小数字改成「火焰 + N 天」，一眼能看出连续了几天；断签、可接回、接回中仍有状态区分。
- **复燃动画**：接回成功的那一刻，余烬长成火焰、一圈很淡的光晕、十几颗火星向上散，数字从旧值滚到新值，约两秒后自动收起。设置里关掉动画、或系统开了「减少动效」时，直接显示最终天数，不撒火星。
- 口径不变：接回只补连续天数，缺口那天不算学习时间，也不产生任何学习记录。

## 小字更清楚

- 状态色（成功 / 警告 / 危险 / 提示）现在有**专用的文字色**：以前拿填充色当小字，浅色主题压在自家浅底上只有 2.5~3.5:1；现在全部提到 4.5:1 以上。
- 三级小字整体加深一档（浅色 56% → 62%，深色 60% → 66%），层级还在，但不用凑近看。
- 半透明玻璃主题上几个临界项单独修了：日历日期数字、主题卡名称、作息分段、统计标签、首页「自己选科目与目标」。
- 新增两道机器门禁：真实像素对比度（78 个组合，要求 0 条低对比）+ 令牌级确定性对比度（216 个组合，每个 ≥4.5:1，最低 5.05:1）。以后改颜色退步会直接让回归失败。
- 顺手修掉一个半夜才会暴露的问题：过了睡觉时间后，首页「距离睡觉」会显示「22 小时 40 分」（算成明天），现在如实显示「已过」。

## 键盘与读屏

- 第一个 Tab 出现「跳到主要内容」，回车直接跳过导航落到正文（HashRouter 下不会把 `#main` 当路由）。
- 浏览器标签页标题会跟着页面变（首页 / 火花 / 统计 / 设置…），读屏切换时不再永远念「学习 OS」。
- 弹层补齐 `aria-describedby`；专注模式补 `aria-modal`，进入时把焦点移进来、退出时还给原来的按钮。
- 「课程表」里原来按钮套按钮，读屏会读成一团；现在是一个条目里并排「编辑」和「删除」两个真按钮。
- 首页长按拖动排序原来只有指针能用；设置 → 外观底部新增「首页排序」，上移 / 下移按钮和拖动共用同一份顺序。
- 输入框焦点环更明显（50% 强调色），小于 0.7rem 的字号统一到 0.7rem；计时状态变化会播报；新增的小输入框都有可访问名。
